# LankaBrandShield AI 🇱🇰

## Project Overview

LankaBrandShield AI is a Sri Lanka-focused research
prototype for analyzing possible digital brand
impersonation using computer vision, machine learning,
deep learning, and multilingual text analysis.

## Problem Statement

Fraudulent websites can imitate legitimate banking
and digital government services.

The project investigates methods for identifying
suspicious visual and domain-related inconsistencies.

## Proposed Features

- Website screenshot analysis
- URL and domain inspection
- Visual brand similarity analysis
- Sinhala, Tamil, and English OCR
- Multimodal phishing risk assessment
- Explainable inspection results

## Technology Stack

- Python
- OpenCV
- PyTorch
- Scikit-learn
- Streamlit
- Git and GitHub

## Project Status

Stage 1: Initial development setup.

## Important Limitation

The application is a research prototype.

Screenshot appearance alone cannot establish whether
a website is legitimate or fraudulent.

Users must independently verify sensitive services
through trusted official channels.
